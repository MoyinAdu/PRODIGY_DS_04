# Twitter Sentiment Analysis Dashboard

## Project Overview

In this project, I analyzed Twitter data to understand public sentiment toward different brands and entities. The goal was to identify how people feel about these brands and present the insights in an interactive Power BI dashboard.

Using the Twitter dataset provided for the task, I cleaned, organized, and analyzed the data to uncover sentiment trends and overall brand perception.

## Data Cleaning and Preparation

Since Twitter data is often unstructured and contains a lot of noise, I used Power Query to prepare the dataset before analysis.

The cleaning process included:

* Removing missing values and empty tweets
* Filtering out irrelevant records
* Standardizing brand and entity names to avoid duplicates
* Organizing tweets into four sentiment categories:

  * Positive
  * Negative
  * Neutral
  * Irrelevant

These steps helped improve data quality and ensured more accurate results.

## Key Findings

### Sentiment Distribution

* Analyzed how tweets were distributed across the different sentiment categories.
* Established an overall view of public opinion within the dataset.

### Brand Sentiment Analysis

* Compared sentiment across different brands and entities.
* Identified which brands received the most positive engagement and which attracted more negative feedback.

### Dashboard Design

* Designed the dashboard to answer key questions quickly and clearly.
* Built an interactive layout that allows users to explore sentiment trends without needing to work directly with raw data.

## Tools Used

### Power BI Desktop

* Built the interactive dashboard
* Created charts and visualizations
* Analyzed sentiment patterns and brand performance

### Power Query

* Cleaned and transformed the dataset
* Filtered and organized tweet data
* Standardized categories and improved data quality

## Conclusion

This project helped me understand how sentiment analysis can be used to measure public opinion on social media. The dashboard provides a clear view of audience sentiment, making it easier to identify positive engagement, negative feedback, and overall brand perception on Twitter.
